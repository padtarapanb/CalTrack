เชื่อมต่อกลุ่ม LINE

สร้าง LINE Official Account แล้วเปิด Messaging API จากนั้นเชิญบอตเข้ากลุ่มของห้องแล็บ

ล่วงหน้า 30 / 14 / 7 วันก่อนถึงกำหนดสอบเทียบ
เครื่องมือเกินกำหนดส่งซ้ำทุกวันจนกว่าจะสอบเทียบ
ผลสอบเทียบไม่ผ่านส่งทันทีหลังอนุมัติผล
ใบรับรองใหม่ออกแล้วส่งลิงก์ใบรับรองให้ผู้รับผิดชอบ

ขอ Group ID (เมื่อเชิญบอตเข้ากลุ่มแล้ว)

LINE ไม่แสดง Group ID ในแอป ต้องให้บอตรับ Webhook แล้วตอบกลับ — ทำครั้งเดียว

  1. Vercel → Environment variables ใส่ LINE_CHANNEL_SECRET (LINE Developers → Basic settings) และ LINE_CHANNEL_ACCESS_TOKEN (แท็บ Messaging API → Issue) แล้ว Trigger deploy
  2. LINE Developers → Messaging API → Webhook URL: https://<โดเมน-vercel-ของคุณ>.vercel.app/api/line-webhook → กด Verify → เปิด Use webhook
  3. LINE Official Account Manager → ตั้งค่า → การตอบกลับ ติ๊ก “อนุญาตให้บัญชีเข้าร่วมกลุ่มและห้องแชท” และปิดข้อความตอบกลับอัตโนมัติ
  4. ในกลุ่มที่เชิญบอตแล้ว พิมพ์ groupid บอตจะตอบ Group ID (ขึ้นต้นด้วย C) — ถ้าไม่ตอบ ให้นำบอตออกแล้วเชิญใหม่ บอตจะตอบเองทันทีที่เข้ากลุ่ม
  5. ใส่ค่าที่ได้เป็น LINE_GROUP_ID พร้อม CALTRACK_API (URL ใน config.js) และ TEST_KEY (ตั้งเอง) → deploy ใหม่ → เปิด /api/line-test?key=ค่าTEST_KEY ต้องมีข้อความเข้ากลุ่ม

สำรอง: ดู Group ID ได้ที่ Vercel → Logs → Functions → line-webhook (บรรทัด “LINE source group …”)

ทำงานอย่างไรเมื่อ deploy บน Vercel

หน้าเว็บเป็นไฟล์ static ส่วนการแจ้งเตือนใช้ Scheduled Function ที่ทำงานตามเวลา โดย token เก็บใน Environment variables ไม่อยู่ในโค้ด

Scheduled Function (ทุกวัน 08:00)→อ่านทะเบียนจาก Google (Apps Script)→LINE Messaging API (push)→กลุ่ม LINE

ไฟล์ในโปรเจกต์ (โฟลเดอร์ api)

line-webhook.mjs  รับ Webhook ตอบ Group ID
notify.mjs        แจ้งเตือนทุกวัน 08:00 (ไทย)
line-test.mjs     ทดสอบส่งข้อความเข้ากลุ่ม
